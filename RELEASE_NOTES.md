Sona 1.0.91

- In-app updates: Sona now checks for new releases and offers an update dialog with What's-new notes. The APK downloads inside the app with a progress bar and goes straight to the Android installer - no browser. (First update prompt you see will be for the NEXT release after this one.)
- Settings also has a manual "Check for updates" row.
- Note: Android asks once for "install apps from this source" - the dialog explains it and opens the right setting. Android's own install confirm screen then finishes the update; that tap is the system's.
